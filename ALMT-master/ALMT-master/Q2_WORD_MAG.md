# 问题二：词位置多模态适配实验

## 为什么做这个实验

`aligned_50.pkl` 的 `text_bert`、语音和视觉都是长度 50 的序列。语音非零位置大多与文本去掉 `[CLS]`、`[SEP]` 后的位置对应：训练集 3391/3395 条、验证集 727/728 条的有效语音长度相符，三个划分均没有在非词位置出现非零语音或视觉特征。训练集有 110 条完全没有视觉特征，模块用掩码跳过这些位置。

原基线把语音和视觉各自汇总为一句话的向量，再与文本融合，因而没有直接利用逐词位置关系。本实验参考 [MAG-BERT（ACL 2020）](https://aclanthology.org/2020.acl-main.214/)：在 BERT 嵌入层之后，按对应位置计算由语音、视觉和文本共同决定的门控位移，并限制位移相对文本向量的大小。这里是面向当前数据和基线的轻量实现，不是原论文的完整复现；句级融合和损失函数与基线相同。

## 运行

在 VS Code 打开 `train_q2_word_mag.py`，选择原来的 PyTorch 解释器，点击“运行 Python 文件”。训练最多 40 轮，并按验证集三分类宏平均 F1 保存最佳模型到 `runs/q2_text_anchor_word_mag/best.pt`。训练完成后，打开 `evaluate_q2_word_mag.py` 点击运行，得到该最佳模型的测试集结果。

参数位于 `configs/q2_reliability_word_mag.yaml`。`word_aligned_mag: true` 启用新模块，`mag_beta: 0.2` 限制单个位置的非语言位移幅度。数据仍读取 D 盘的 `aligned_50.pkl`；该实验不能直接用于未对齐特征文件。训练程序会先检查词位置布局。

## 对照与判断标准

固定原基线的随机种子、学习率、批次、轮数和损失函数，仅增加词位置模块。原基线最佳验证集宏平均 F1 为 0.6308；用其最佳检查点遮去模态重算验证集，文本单独 0.6255、遮去语音 0.6240、遮去视觉 0.6288。原模型对语音和视觉已有一点利用，但幅度很小。

本实验尚未完成全量训练，不能声称提升。优先比较新实验的**最佳验证集宏平均 F1**是否超过 0.6308，再对选中的最佳检查点评估测试集。原基线测试集宏平均 F1 为 0.6581。两组测试须使用相同三分类头指标比较，不能把回归分数阈值分类结果混在一起。
