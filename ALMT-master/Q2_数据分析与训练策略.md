# E 题问题二：数据分析与训练策略

## 1. 任务目标

题面要求同时预测情感极性与连续情感强度，并在局部模态信息缺失时保持稳定。情感极性有负面、中性、正面三类，强度在 `[-3,3]`。两项输出应分别评价：分类看 Accuracy 和 F1，强度看 MAE 和 Pearson。极性不必由强度的固定阈值产生；原始标注规定只有强度恰好为 0 才是中性。

当前阶段按用户要求先建立完整模态基线，不在训练中模拟局部模态缺失。模型结构已对声学、视觉的全零时间步进行掩码处理；正式完成问题二时仍需对缺失类型、位置和时长做验证实验，并产生附件 3 的预测文件。

## 2. 附件 2 已对齐数据的实际情况

| 划分 | 样本数 | 负面 | 中性 | 正面 |
|---|---:|---:|---:|---:|
| train | 3395 | 967 | 758 | 1670 |
| valid | 728 | 206 | 184 | 338 |
| test | 727 | 207 | 158 | 362 |

三组按原视频 ID 分开，检查时训练和验证没有共享原视频 ID。中性样本在训练集占 22.33%，是三类中最少的一类，但此前把中性抽样权重提高到 1.7，验证中性召回率仍停留在 43.48%，说明仅改变抽样概率不能解决主要误差。

`classification_labels` 与 `regression_labels` 的关系：全部中性强度为 0；负面强度在 `[-3,-1/3]`；正面强度在 `[1/6,3]`。训练集中 691 条非中性样本的强度绝对值不超过 0.5，占非中性的 26.2%。因此，强度回归的小误差可能使较多弱情感样本跨越人工设定的分类阈值。`±0.2` 与原类别标签还存在少量不完全一致之处。

附件 2 的长度统一为 50。训练集语音与视觉的全零时间步分别约为 54.75% 和 57.21%；语音通常是一段连续有效区间，两端为零填充。视觉另有 110 条样本所有时间步全零。原 ALMT 对 50 个位置直接加入位置向量并参与注意力，未显式排除这些无效位置；新模型先识别有效帧，再做掩码池化。语音个别数值的绝对值可超过 200，故归一化参数只从训练集有效帧计算，标准化后限制极端值。

## 3. 模态信号检查

使用训练集拟合标准化和逻辑回归，在验证集上比较掩码均值、标准差摘要（同样的 `C=0.01`）：

| 输入 | Accuracy | Macro-F1 |
|---|---:|---:|
| 文本 | 56.46% | 0.535 |
| 语音 | 47.39% | 0.333 |
| 视觉 | 45.19% | 0.324 |
| 文本＋语音 | 56.73% | 0.537 |
| 文本＋视觉 | 56.73% | 0.538 |
| 文本＋语音＋视觉直接拼接 | 56.04% | 0.529 |

这些是轻量诊断基线，不能与完整 ALMT 的模型能力直接等同。它们表明文本是主要信号，语音和视觉有小幅补充，直接拼接可能加入噪声。因此采用文本锚定、按样本学习语音和视觉贡献的门控融合。

## 4. 当前训练策略

新实验入口为外层 `run_q2_reliability.py`，配置为内层 `ALMT-master/configs/q2_reliability.yaml`：

1. 文本：`text_bert` 经本地 BERT 编码；冻结词嵌入及前 9 个 Transformer 层，仅微调后 3 层。
2. 语音和视觉：仅用非零有效时间步计算训练集统计量，并在样本内对有效帧做注意力池化。全零视觉输入的贡献设为零。
3. 融合：文本作为主干，语音、视觉分别通过可学习门控添加。门控初始偏向小贡献，以免弱模态冲淡文本语义。
4. 目标：三分类交叉熵为主，带轻度类别权重与标签平滑；连续强度使用 Huber 损失作辅助。分类头直接输出情感极性，分数头单独输出强度。保留 `±0.2` 分数分类作为对照，不作为主要极性输出。
5. 选择：按验证 Macro-F1 保存权重，同时报告各类召回、准确率、MAE 与 Pearson；测试集在模型选择结束前不参与调参。

新模型是否优于已有 ALMT，须以同一验证集上的完整训练结果判断。模型容量、类别权重与阈值均不应根据测试集调整。
