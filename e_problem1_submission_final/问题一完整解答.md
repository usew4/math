# E 题问题一：100 条视频的三模态情感特征与时序对齐

## 1. 任务与数据

赛题要求基于附件 1 的 100 条英文原始视频，自行生成文本、语音、视觉三模态时序特征，说明处理流程、特征定义、对齐规则、有效长度和填充规则，并给出能逐条追溯的视频编号、特征文件及处理记录。本结果只解决问题一；标签仅写入汇总表用于核对，不参与特征拟合，也未使用附件 2 的预提取特征代替自主提取。

以 `video_id__clip_id` 为唯一键，把 `label-100.xlsx` 的转写、标签与 ZIP 中附件 1 的 MP4 一一匹配。原视频逐个临时解压，统一解码音频为 16 kHz 单声道；视觉每秒采样 2 帧。100 个编号均与 100 个输出特征文件对应。

## 2. 统一时间轴与数据结构

令 $T_i$ 为样本 $i$ 的视频容器时长与解码音频时长两者的较大值，定义 50 个半开时间区间

$$I_{ik}=[kT_i/50,(k+1)T_i/50),\qquad k=0,\ldots,49.$$

三模态按原始时间戳投影到这些区间，形成 $X_i^{(t)}\in\mathbb R^{50\times37}$、$X_i^{(a)}\in\mathbb R^{50\times17}$、$X_i^{(v)}\in\mathbb R^{50\times65}$。`bin_center_sec[k]=(k+0.5)T_i/50` 记录实际秒数。因此 50 是序列位置数，**每个样本的单元秒数并不相同**。本方案在原时长上切分，不裁短视频，也不把音频单独拉伸。每段视频的原时长、音频时长、词数和采样帧数记录在全量表中。

文本按词时间段与 $I_{ik}$ 的重叠长度加权汇聚；音频将 10 ms 步长的声学帧按中心时间分箱并取均值；视频将 2 fps 采样帧按采样时间分箱。无有效观测的单元填 0，同时保留 `speech_mask`、`visual_frame_count`、`mp_face_count`；下游模型不能把零值直接解释成中性情感。人脸系数只在检测到人脸的帧上求均值，`mp_face_count=0` 时系数填 0。多人物时 Face Landmarker 仅分析 1 张人脸。

## 3. 文本情感特征与词级定位

附件 1 已给出英文转写，但没有词级时间。先用 PocketSphinx 5.0.4 的英语声学模型与发音词典，对转写和原音频做词级强制对齐。模型给出 10 ms 声学帧上的词起止位置；表 `word_alignment.csv` 保留 `sample_id、word_index、token、start_sec、end_sec、method、bin`。词典外词及部分未匹配声学片段的词利用相邻已对齐词的时间间隔按词长插值，标为 `oov_or_partial_interpolation`；整条对齐失败时使用语音活动加词长分配的原方案，标为 `vad_orthographic_fallback`。这些标记使估计位置不会被误报为声学对齐。

每词的文本向量为 37 维：32 维确定性的字符三元组有符号哈希、4 维 VADER 情感分数（负、中、正、复合），以及所在时间单元的词数。VADER 以目标词前后各至多 2 词的窗口计算，以保留部分否定与程度词上下文。对词区间 $[s_j,e_j]$ 和网格 $I_k$，取 $w_{jk}=|[s_j,e_j]\cap I_k|$；前 36 维为 $\sum_j w_{jk} f_j/\sum_j w_{jk}$，第 37 维为与该单元重叠的词数。空单元填 0。

**适用边界**：字符哈希用于词形信息和可重复映射，不是预训练语义向量；VADER 是词典情感线索，对讽刺、复杂否定和语境转换有局限。强制对齐估计的是“给定转写下词在声学信号的位置”，不验证转写是否准确。音频背景声、截断词和词典外词会影响时间精度。

## 4. 语音情感特征

音频解码为 16 kHz 单声道，32 ms 分析窗、10 ms 步长。每个声学帧计算 13 维 MFCC、1 维对数 RMS、1 维过零率、1 维归一化频谱质心、1 维自相关基频代理值，共 17 维。各单元内按声学帧均值汇聚。RMS 反映响度变化，基频代理值反映部分语调变化，MFCC 和质心描述谱形；这些是**可用于情感识别的声学线索**，不能仅凭单项直接判定情感。`speech_mask` 是基于片段相对能量阈值的活动标记；背景音乐可能使其误检。

## 5. 视觉情感特征

每秒采样 2 帧，并缩放到约 320 像素宽。65 维视觉向量由原始 12 维可解释描述量、1 维 MediaPipe 人脸出现比例、52 维 Face Landmarker 表情形变系数组成。前 12 维包括 LBP 正面人脸检测、相对位置和大小、亮度、饱和度、清晰度及帧间画面变化；52 维包括眉、眼、颌、嘴角等局部形变，准确名称与顺序见 `visual_feature_names.json`。这些形变系数是面部动作表征，**不是直接的喜怒哀乐类别或强度**。没有检出人脸时保留缺失标记；侧脸、遮挡、镜头切换会降低覆盖率。

## 6. 全量计算结果与核查

| 指标 | 结果 |
|---|---:|
| 原视频与特征文件 | 100 条 / 100 个 |
| 转写词总数 | 1,932 |
| 声学强制对齐词 | 1,659（85.9%） |
| 局部插值词 | 31（1.6%） |
| 语音活动回退词 | 242（12.5%） |
| 至少有一个强制对齐词的片段 | 85 / 100 |
| 所有词均强制对齐的片段 | 68 / 100 |
| 视觉采样帧 | 1,570 |
| MediaPipe 检出人脸帧 | 1,284（81.8%） |
| 至少有一个人脸帧的片段 | 87 / 100 |
| 特征矩阵形状 | 文本 50×37；语音 50×17；视觉 50×65 |

`verify_final.py` 实际逐条核查了 100 个文件的形状、有限值、单调时间轴、词数、采样帧数、强制对齐词数、面部检测帧数及词区间边界，全部通过。逐条结果见 `output_final/all_100_summary.csv`，质量统计见 `output_final/quality_report.json`。`output_final/example_text_audio_video.png` 将同一视频的词区间、音频能量、面部系数和实际视频帧放在同一秒级坐标上，能直观看到对应关系。

为描述三模态在统一时间单元上的关系，仅在两个变量都有效的单元计算 Spearman 秩相关。词情感复合分与语音响度的 $\rho=-0.0194$（3,405 个有效单元），与基频代理值为 $0.1151$（3,144 个单元），与嘴角上扬系数为 $-0.0789$（1,056 个单元）；响度与嘴角上扬为 $-0.0445$（998 个单元）。总体关系较弱，说明简单的同一时刻单变量相关不足以替代后续时序融合模型。这些数值仅是描述性统计：同一视频的单元并非独立样本，也没有控制说话人和场景差异，不能据此作因果结论。完整表见 `cross_modal_associations.csv`。

## 7. 文件、追溯与复现

- `output_final/features/<video_id>__<clip_id>.npz`：每条样本的 `text`、`audio`、`visual`、`bin_center_sec` 和三个有效性记录。
- `output_final/all_100_summary.csv`：编号、标签、原有效时长、对齐数量、缺失数量、各模态维度、视觉覆盖率，100 行。
- `output_final/word_alignment.csv`：每词原文、原始秒数、公共序列位置、定位方法。
- `output_final/visual_frame_log.csv` 与 `face_frame_log.csv`：每个实际抽取帧的原时间和人脸检测情况。
- `output_final/visual_feature_names.json`：视觉列的具体意义；`run_metadata.json`：模型、参数、数据来源。
- `output_final/example_text_audio_video.png`：典型样本核验图。

复现顺序：安装 `requirements.txt` 中的 Python 依赖与 MediaPipe 0.10.14，使用本目录的 `face_landmarker.task`，依次运行 `extract.py`、`upgrade.py`、`add_faces.py`、`make_example.py`、`analyze_cross_modal.py`、`verify_final.py`。所有脚本默认读取题目数据 ZIP 的原路径，可通过命令行参数改写前三个阶段的源位置。`face_landmarker.task` 来自 [Google 官方 MediaPipe 模型地址](https://storage.googleapis.com/mediapipe-models/face_landmarker/face_landmarker/float16/1/face_landmarker.task)，SHA-256 为 `64184e229b263107bc2b804c6625db1341ff2bb731874b0bcc2fe6544e0bc9ff`。

本题只需自主生成特征，不需为问题一训练情感预测器。若问题二、三使用附件 2 的训练特征，其维度和预处理流程与本题自主生成文件不同，应单独处理。

## 8. 方法依据

- [CMU-MOSEI 原论文](https://aclanthology.org/P18-1208.pdf)：多模态语音、文本、视觉信号及词级对齐的研究背景。
- [PocketSphinx 官方项目说明](https://github.com/cmusphinx/pocketsphinx/blob/main/README.md)：给定转写的声学强制对齐工具。
- [MediaPipe Face Landmarker 官方文档](https://ai.google.dev/edge/mediapipe/solutions/vision/face_landmarker/python)：人脸关键点与表情形变输出。

本实现采用这些工具中的基础处理思想；上面的定长分箱、具体特征组合、缺失标记和数据表均为针对本题自行设计与生成。
